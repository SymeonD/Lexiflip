# Lexiflip

This is a personal project that I am working on to help me learn Flutter. The goal of this project is to create a simple flashcard app that allows users to create and study flashcards.

I did use this app during my trip in Thailand, and it helped me through the 3 months I was there. I was able to improve the app and create new features based on my experience using it. I hope to continue improving this app and make it a useful tool for language learners.

## Getting Started

To get started with this project, you will need to have Flutter installed on your machine. You can follow the instructions on the official Flutter website to install it.

Once you have Flutter installed, you can clone this repository and run the app on your device or emulator.

Please note that this project is still in development, and there may be bugs or incomplete features. If you encounter any issues, please feel free to open an issue on the GitHub repository.
Additionally, some features are not yet usable on all platforms, such as the ability to share decks with other users. I am working on implementing this feature on IOS in the future, but for now, it is only available on Android.
